# 7HUB GEN - Gerador Spotify Premium

Gerador de links Spotify Premium com 3 meses grátis. Crie múltiplos links com animações neon vermelhas.

## 🚀 Funcionalidades

- Gera links Spotify Premium aleatórios
- Copiar todos os links gerados
- Baixar links em arquivo TXT
- Animações neon vermelhas
- Interface moderna e responsiva

## 📋 Como Usar

1. Digite a quantidade de links desejada (1-500)
2. Clique em "GERAR"
3. Use "COPIAR TODOS" ou "BAIXAR TXT"

## 🌐 Deploy no Vercel

Este projeto está configurado para funcionar perfeitamente no Vercel.

```bash
# Clone o repositório
git clone https://github.com/erickmattosmattos469-dot/Gerador-spotify.git

# Acesse a pasta
cd Gerador-spotify

# Abra no navegador
# O arquivo index.html será servido automaticamente pelo Vercel
```
